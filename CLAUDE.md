# Regeln für dieses Projekt (Beleg-Sortierer)

Dieses Repository wird ÖFFENTLICH (GitHub Pages, Link in einer Bewerbung).

- Nur fiktive Testdaten. Niemals echte Mandanten- oder Kundendaten.
- Keine persönlichen Daten: keine private E-Mail, keine Adresse, keine Gesundheitsdaten.
- Nichts behaupten, was das Tool nicht kann. Grenzen offen in README und Demo nennen.
- René muss jede Zeile im Gespräch erklären können: einfacher Code, deutsche Kommentare,
  nach jeder Änderung kurz auf Deutsch erklären, was sie tut und warum.
- Nach Änderungen an einstellungen/ oder eingang/: `python3 demo_daten_exportieren.py` ausführen.
- Die Logik in docs/index.html muss zu beleg_sortierer.py passen (gleiche Ergebnisse).
- Vor jedem Commit: `python3 -m unittest -v` muss grün sein.
